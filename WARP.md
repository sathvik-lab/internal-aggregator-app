# WARP.md

`internal-aggregator-app` is an Expo React Native app for document management and daily compliance checklists.

- This branch contains real application code.
- Main entrypoint: `App.js`
- App source: `src/`
- Backend: Firebase Auth, Firestore, and Storage via `src/services/`
- Main npm scripts: `start`, `android`, `ios`, `web`
- Extra script present: `convert:osha`
- Quality scripts: `lint`, `format`, `test`
